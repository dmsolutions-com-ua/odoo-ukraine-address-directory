🌍 Geodata Connector

Version 18.0.1.0.0

Integration with Geodata.online API for address autocomplete and normalization in Ukraine.

✨ Features

Address Autocomplete

Real-time address suggestions from Geodata.online API with comprehensive Ukrainian address database.

Wizard-Based UI

User-friendly wizard for address selection directly from res.partner forms.

Automatic Field Population

Auto-fills street, city, zip code, state, and geographic coordinates.

Multi-language Support

Ukrainian and Russian language interfaces for API requests.

📋 Requirements

  • Odoo 18.0 Community or Enterprise
  • kw_api_connector module
  • kw_http_request_log module
  • kw_mixin module
  • base_geolocalize module
  • Geodata.online API key (register here)

🚀 Quick Start

  1. Install the module from Odoo Apps
  2. Navigate to Settings → Address (GEODATA) → API Credentials
  3. Create new credential and enter your API key
  4. Test connection
  5. Open any partner form and click "🌍 Address Wizard"
  6. Search and select address
