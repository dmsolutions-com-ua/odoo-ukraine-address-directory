Коли модуль встановлено та налаштовано, то на картці Контакта з’являється нова вкладка Інформація про адресу та для кожного нового контакту автоматично зазначається країна Україна.

Класичний спосіб введення адреси

Починаємо введення адреси в такій послідовності:

  1. Країна (Україна)
  2. Населений пункт
  3. Вулиця і будинок

Підказки з’являтимуться автоматично, щойно ви введете три або більше символів (в Україні є кілька назв населених пунктів які складаються з двох літер, тому ці населені пункти можна знайти користуючись додатковим методом пошуку). Система звернеться до довідника і покаже відповідні варіанти, з яких можна обрати потрібний.

Після появи підказки ви можете обрати потрібний населений пункт.

Модуль автоматично заповнить поля «Місто» та «Область», а також покаже поля з інформацією про район і громаду.

Поруч з актуальною назвою населеного пункту в дужках відображається стара назва (до перейменування), якщо раніше відбувались перейменування.

Користувач може вводити як актуальну назву населеного пункта так і стару - модуль так само надасть відповіді правильні підказки.

Наступним кроком вводимо назву вулиці.

Після введення трьох або більше символів система запропонує список усіх вулиць, у назві яких містяться введені символи.

Якщо ви введете стару назву, у підказках автоматично з’явиться її актуальна, нова назва, а в дужках буде зазначена стара.

Наступний крок - це отримання номеру будинку по вибраній вулиці.

Для цього потрібно набрати цифру та отримати список із підказками по існуючим номерам будинків в довіднику.

Вибравши відповідний номер будинку автоматично буде визначений та заповнений актуальний індекс цієї адреси.

Додатковий спосіб внесення адреси

Переходимо на вкладку: Інформація про адресу

В цьому полі допустиме введення адреси в різних комбінаціях:

  1. Населений пункт, Вулиця і будинок
  2. Район, Населений пункт, Вулиця і будинок
  3. Область, Населений пункт, Вулиця і будинок
  4. Область, Район, Населений пункт, Вулиця і будинок

Елементи адреси вносяться через пробіл.

Приклади комбінацій внесення:

1. Пошук по назві населеного пункту - формується підказка по співпадінням у всіх областях України.

Результат - отримаємо в підказці 8 населених пунктів.

2. Пошук по назві району та назві населеного пункту - формується підказка по співпадінням у відповідних районах України.

Результат - отримаємо в підказці 2 населених пункта.

3. Пошук по назві області та назві населеного пункту - формується підказка по співпадінням у відповідних районах України.

Результат - отримаємо в підказці 3 населених пункта.

4. Пошук по назві області, назві району та назві населеного пункту - формується підказка по співпадінням у відповідних районах України.

Результат - отримаємо в підказці 2 населених пункта.

Обираємо відповідну вулицю та номер будинку:
Після початку введення надаються підказки існуючих номерів будинків, які починаються із відповідних цифр.

Вкладка: Інформація про адресу

На цій вкладці надається корисна інформація по адресі що ввели.

Розділ Деталі адреси містить:

  • КАТОТТГ - Актуальний державний код територіальної одиниці за новим класифікатором після реформи.
  • КОАТУУ - Старий код адміністративно-територіального устрою, що використовувався до впровадження КАТОТТГ.
  • Статус територій згідно наказу - Відображає  статус території на дату отримання (оновлення) адреси. (Згідно наказу «Про затвердження Переліку територій, на яких ведуться (велися) бойові дії або тимчасово окупованих російською федерацією» від 28.02.2025 № 376.
  • Дата отримання (оновлення) адреси - поточна дата запиту

Розділ Повні адреси для документів:

  • Готовий, автоматично сформований рядок для документів. Модуль складає адресу у форматі який визначений в налаштуваннях, придатному для офіційних документів.
  • Транслітерація адреси (якщо ввімкнено в налаштуваннях). Автоматично створюється англомовна версія адреси відповідно до чинних правил української транслітерації. Формат зберігає структуру української адреси, але всі елементи подаються латиницею.

Розділ Повні адреси для листів:

  • Готовий, автоматично сформований рядок адреси для поштових конвертів. Модуль складає адресу у форматі який визначається користувачем (адміністратором) в налаштуваннях, згідно правил.
  • Транслітерація адреси (якщо ввімкнено в налаштуваннях). Автоматично створюється англомовна версія адреси відповідно до чинних правил української транслітерації. Формат зберігає структуру української адреси, але всі елементи подаються латиницею.

Зазначені розділи прискорюють перенесення адреси в інші форми та  шаблони простим натисканням кнопки.
